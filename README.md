# HTML‑CSS‑Java‑Script‑Projects

## 📖 Overview
A curated collection of beginner‑level web development projects that practice core **HTML5**, **CSS3**, and **JavaScript** concepts. Each sub‑folder contains a self‑contained app (e.g., a digital clock, a weather widget, a quiz, a to‑do list, etc.) that can be opened directly in a browser.

## ✨ Features
- **Variety of mini‑apps** – age calculator, crypto‑currency website, currency converter, digital clock, drag‑&‑drop, image search, portfolio, quiz, random password generator, rock‑paper‑scissors, text‑to‑speech, tic‑tac‑toe, to‑do list, weather app.
- **Responsive layouts** using Flexbox/Grid and media queries.
- **Pure front‑end** – no build tools, servers, or frameworks required.
- **Clear separation** of HTML, CSS, and JS for each project, making it easy to study individual techniques.

## 🛠️ Tech Stack
- **HTML5** – semantic markup and form elements.
- **CSS3** – Flexbox, Grid, animations, custom properties.
- **Vanilla JavaScript (ES6+)** – DOM manipulation, fetch API (for weather/search), localStorage (to‑do list), Web Speech API (text‑to‑speech).
- Optional CDN libraries (e.g., Font Awesome, Bootstrap) used where appropriate.

## 🚀 Getting Started
1. **Clone the repo**
   ```bash
   git clone https://github.com/imtiazaly/HTML-CSS-Java-Script-Projects.git
   cd HTML-CSS-Java-Script-Projects
   ```
2. **Open a project** – navigate into any folder and double‑click `index.html` or run:
   ```bash
   start "Age Calculator App\index.html"
   # replace the path with the desired project
   ```
   No npm, webpack, or server setup is required.
3. **Explore & tinker** – edit the HTML/CSS/JS files to experiment with concepts you are learning.

## 📖 Learning Outcomes
- Build and style interactive UI components from scratch.
- Consume public APIs with `fetch` (weather, image search).
- Manage state locally using `localStorage`.
- Apply responsive design principles.
- Gain confidence in structuring front‑end projects.
